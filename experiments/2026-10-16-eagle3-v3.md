# EAGLE-3 draft head v2/v3 (reasoning-trace data, queue training on 2 GPUs)

- **Date**: 2026-10-16 (trained), evaluated 2026-10-19
- **Task**: Speculative decoding for Solar
- **Host / device**: 2x A100 80GB (GPU0 extractor 45% cap, GPU1 extractor 40% + trainer 42%), Solar bf16 teacher by layer streaming
- **Commit**: c14a82c

## Question
Does reasoning-style training text (Solar decodes an English `<|think|>` trace first) and 30x more data raise acceptance?

## Setup
- v2: online extract+train on 20.3M tokens (Nemotron chat reasoning=on 2.8k [CC-BY-4.0], Mixture-of-Thoughts 8k, v1 chat), stopped at chunk 40/209.
- v3: from v2@40; Glaive reasoning-v1 45k (Apache-2.0) + all v2 data = 87.5M tokens, 898 chunks; two extractors -> /dev/shm queue -> one trainer (PASSES=1, TOK_BUDGET 4096, TTT 5, LR 1.2e-4 cosine). 6.2 h.
- Data format: prompt (chat template) + `<|think|>R<|end|><|begin|>assistant<|content|>A<|end|>`.

## Command
```bash
python3 eagle3/prep3.py data_v3.pt 45000 2048
CUDA_VISIBLE_DEVICES=0 GPU_FRAC=0.45 python3 eagle3/extract_queue.py data_v3.pt 0 2 /dev/shm/q 98304 5
CUDA_VISIBLE_DEVICES=1 GPU_FRAC=0.4  python3 eagle3/extract_queue.py data_v3.pt 1 2 /dev/shm/q 98304 5
CUDA_VISIBLE_DEVICES=1 GPU_FRAC=0.42 TOK_BUDGET=4096 python3 eagle3/train_queue.py /dev/shm/q 2 898 draft_v2_c40.pt draft_v3.pt
python3 eagle3/eval.py draft_v3.pt evalgen/e* --k 6
```

## Results
| draft | train acc (step 1 / 5) | tau k=6 on Solar's own outputs | per prompt |
|---|---|---:|---|
| v1 | 0.56 / 0.39 | 1.42 | 1.29-1.60 |
| v2@40 | 0.56 / 0.36 | 1.52 | 1.34-1.91 |
| v3 | 0.67-0.69 / 0.53-0.55 | **1.92** | 1.59-2.56 |

v3 accepted-length histogram (k=6, 2512 chains): [1263, 666, 326, 138, 59, 22, 38].

## Conclusion
Reasoning-style data helps (+0.5 tau) but 1.92 is still under the ~2.5 needed before multi-token verification pays on
this offload engine. Next: self-distillation on Solar's own generations (exact match of the target distribution),
more epochs over v3, a 2-layer draft.
