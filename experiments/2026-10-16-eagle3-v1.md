# EAGLE-3 draft head v1 (chat data)

- **Date**: 2026-10-16
- **Task**: Speculative decoding for Solar
- **Host / device**: GPU1 A100 80GB (shared), Solar bf16 teacher via layer streaming
- **Commit**: bb532fd

## Question
Acceptance length of a self-trained EAGLE-3 head (no Solar draft model exists).

## Setup
Data: UltraChat 1500 + KoAlpaca 4000 in Solar chat template, 2.78M tokens. Features (layers 1/23/44 + final norm) by `eagle3/extract.py`
(argmax check 12/12 vs the NPU engine). Draft: 1 decoder layer, fc 3H->H, draft vocab 32768, TTT 5, 3 epochs.
Eval: Solar's own exact greedy outputs (NPU engine, 8 prompts x 320 tokens, `eagle3/evalgen`).

## Command
```bash
TORCH_DEVICE_BACKEND_AUTOLOAD=0 CUDA_VISIBLE_DEVICES=1 python3 eagle3/train.py feats_v1 draft_v1.pt 3 5
python3 eagle3/eval.py draft_v1.pt evalgen/e* --k 6
```
